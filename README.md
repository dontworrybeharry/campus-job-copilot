# Campus Job Copilot · 秋招作战台

一个打开就能用的秋招求职工作台，内置可以直接操作平台的 AI 助手：**粘贴岗位 JD，自动从你的经历里挑出最匹配的要点，生成严格一页的中文简历（可编辑 Word / PDF）**，并提供网申逐项复制、岗位匹配分析、投递看板和留学生届别自查。

- 不需要注册、没有服务器；AI 助手使用你自己的 Claude / ChatGPT API Key（可选）
- 所有数据只保存在你自己的浏览器里
- 单个 HTML 文件，下载后双击即可离线使用

> 在线使用：https://dontworrybeharry.github.io/campus-job-copilot/

## 功能

| 模块 | 做什么 |
| --- | --- |
| AI 助手 | 连接 Claude 或 ChatGPT（填自己的 API Key），AI 通过工具直接操作平台：读你的经历、分析 JD、生成并改写一页简历（仍受防编造拦截）、整理网申字段、更新投递看板、模拟面试并保存复盘 |
| 我的经历 | 填一次基本信息、教育背景和经历要点；旧简历整段粘贴即可导入。每条要点会提示「没有结果数字」「偏长」「以协助开头」 |
| 快速投递 · 一页简历 | 按 JD 识别岗位方向和必备能力，自动取舍经历与要点，按 A4 实测排版保证一页，自动避免「几个字独占一行」；可上传证件照放在右上角；导出可编辑 Word 或存为 PDF |
| 历史简历 | 导出 Word、存 PDF 或记录投递时自动存一版；之后直接在简历页面上点击文字修改，实时显示一页占用，再导出 |
| 快速投递 · 按 JD 改写 | 一键生成改写提示词，复制到任意 AI（ChatGPT、DeepSeek、豆包、Kimi、通义千问、元宝、Claude、Gemini 均可），把回答贴回来自动替换并保持一页；自动拦截原文没有的数字和「协助」改「主导」这类拔高 |
| 快速投递 · 网申填表 | 网申常见字段逐项复制，经历描述按 JD 相关度排序，可切换 200 字精简版 |
| 快速投递 · 岗位分析 | JD 逐条对照你的经历，标出有证据 / 弱证据 / 缺口；硬技能对照与补法；必备能力覆盖；简历体检 |
| 快速投递 · 深度分析 | 生成八段式 JD 深度分析提示词（岗位画像、知识体系、交付物、工作方法、判断框架、典型场景、进阶建议） |
| 投递看板 | 按阶段管理岗位，记录截止日期、渠道、内推码、JD 和复盘 |
| 届别与留学生 | 输入毕业 / 学位授予日期，逐家判断 2027 届毕业时间窗口；整理国内 base、做海外业务的岗位 |

## 本地使用

1. 下载本仓库（Code → Download ZIP），解压。
2. 用 Chrome / Edge / Safari 打开 `index.html`。
3. 第一次可以点「载入示例看看效果」（虚构的示例同学），看完在「备份与隐私」里清空，再填你自己的经历。

## 浏览器插件（extension 文件夹）

1. Chrome 打开 `chrome://extensions`，开启右上角「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本仓库的 `extension` 文件夹；本地打开 `index.html` 时，还要在插件详情里开启「允许访问文件网址」。
3. 打开平台 →「AI 助手」→「同步档案到插件」。
4. 在招聘网站：点插件「抓取 JD」把岗位加入投递看板；在网申页面点「填写当前页面」，按档案自动填写空着的字段并附上最新简历。**插件不会点提交，请检查后由你本人提交。**

## Safari / 任意浏览器：书签工具

Safari 扩展需要用 Xcode 打包，所以另外提供了两个不用安装的书签工具，Safari、Chrome、Edge 都能用：

1. 打开平台 →「AI 助手」→ 左侧「Safari / 任意浏览器：书签工具」，按提示把「抓取 JD」「填网申」两个按钮拖到收藏栏（Safari 先按 ⌘⇧B 显示收藏栏）。
2. Safari 需要在「设置 → 高级」勾选「在菜单栏中显示开发菜单」，再在「开发」菜单里勾选「允许来自智能搜索栏的 JavaScript」。
3. 在岗位详情页点「抓取 JD」→ 复制弹出的文字 → 粘贴到平台「快速投递」的 JD 框或 AI 助手对话框，公司、岗位、JD 会自动识别。
4. 在网申页面点「填网申」，按档案填写空着的字段。书签工具不会点提交；简历附件需要手动上传；档案改动后要重新拖一次「填网申」。

## 部署成网址（GitHub Pages）

Fork 本仓库 → Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / `(root)` → 保存。几分钟后即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。每个访问者的数据依然只存在自己的浏览器里。

## 隐私

- 数据保存在浏览器 localStorage，不上传任何服务器，也不会随 HTML 文件分享出去。
- 只有点击「打开 AI」「官网」等外链时才会离开页面。
- 使用 AI 助手时，API Key 只保存在你的浏览器里（不写入备份文件），请求从浏览器直接发往 Anthropic / OpenAI，对话中会把你的经历发送给你选择的模型服务商。
- 浏览器插件只在你点击时读取或填写当前页面，数据存在插件本地，不上传。
- 换电脑、换浏览器或清理浏览器数据后会看不到数据，请在「备份与隐私」定期导出 JSON。

## 说明与限制

- 一页测量按宋体字宽估算并收紧行尾孤字，导出 Word 后建议在 Word 里确认仍是一页。
- 「届别与留学生」里的公司毕业时间口径核实于 2026-09-17，多来自转载公告并附来源链接，会过时，投递前以官网为准。欢迎提 PR 更新。
